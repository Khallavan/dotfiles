# Portable interactive Linux installer

## Objective and rationale
Make dotfiles installation interactive and safe on Debian-like, Fedora-like and Arch-like systems (including CachyOS), with minimal portable Zsh adjustments. Existing installer assumes Fedora/Homebrew and personal paths.

## Authorized scope
- English-only prompts, help, errors and summaries; no localization framework.
- Native apt-get/dnf/pacman dependency installation, grouped explicit confirmation.
- Validate the running checkout. If ~/dotfiles is absent, offer to create a symlink to that checkout; never replace existing paths. Create required destination directories with consent.
- Preview Stow conflicts without adopting or overwriting files.
- Optional TPM and Homebrew restoration; validated, explicitly confirmed login-shell change.
- Guard optional Zsh integrations and remove personal paths. Preserve tmux; herdr migration is deferred.
- No real package installation, network bootstrap or shell changes during development/testing.
